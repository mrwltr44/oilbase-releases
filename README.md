# Oilbase - публичные сборки

Здесь лежат готовые сборки системы учёта нефтепродуктов Oilbase и сведения о текущей версии. Исходный код закрыт.

## Что тут есть

- `version.json` - номер текущей версии и описание изменений
- `oilbase-installer.exe` - установщик сервера и рабочего места для Windows

## Как это используется

Сервер на объекте обращается сюда, чтобы узнать, не вышла ли новая версия, и сообщает об этом пользователям. Телефоны и рабочие места в интернет не выходят - они спрашивают только свой локальный сервер.

Если у объекта нет выхода в интернет, файл обновления приносят вручную - система работает одинаково в обоих случаях.
